SET UP YOUR OWN STUDIO

Install ClipHunter

The public website hosts the download and guide. Your video editor, stream files, speech models and renders stay on your computer in the folder you choose.

STEP 01

Install Docker

Install and start Docker Desktop for Mac or Docker Desktop for Windows. Linux users can install Docker Engine and Compose. If using an external drive, allow Docker access to your chosen folder.

STEP 02

Download the project

Download and extract the source bundle. It contains the app and setup files; it contains no videos, passwords or cookies.

Download source bundle ↓
STEP 03

Choose a storage folder

Open Terminal or PowerShell in the extracted ClipHunter folder and run the command for your computer. The script asks where to put your media and models.

Mac or Linux

bash scripts/setup-local.sh

Windows PowerShell

.\scripts\setup-local.ps1

Use a path such as /Volumes/Samsung 512/ClipHunter or D:\ClipHunter. The first build can take several minutes.

STEP 04

Open ClipHunter

Open http://localhost:3000. Create your own workspace password on the first screen. The app stores its password hash in the config folder under your chosen storage folder.

To start later, run docker compose --env-file .env.docker up -d. To stop, run docker compose --env-file .env.docker down. Stopping does not delete your chosen storage folder.

AI-ASSISTED OPTION

Let a coding assistant guide setup

Attach the downloaded project and AI setup instructions to a coding assistant that has access to your computer and terminal. It will ask which folder you want, run the local setup, and verify the app. A chat without computer access can explain the steps for you.
